Tentang Website

⚡

Electronic Calculator

Electronic Calculator merupakan website yang dibuat untuk membantu melakukan perhitungan dasar dalam bidang elektronika. Website ini menyediakan berbagai kalkulator seperti Hukum Ohm, daya listrik, resistor, LED, energi, pembagi tegangan, kapasitor, dan konversi satuan.

Website ini menggunakan Python dengan framework Flask sebagai bagian backend dan HTML, CSS, serta JavaScript sebagai bagian frontend.

Proses perhitungan dilakukan melalui komunikasi antara JavaScript dan Flask menggunakan metode Fetch API sehingga hasil dapat ditampilkan tanpa melakukan reload halaman.
